# Cozy Bakery Cafe 🥐

A relaxing, cozy bakery simulation web game built with **React**, **TypeScript**, **Vite**, **Tailwind CSS**, and **Web Audio API**.

No timers, no rush, no pressure—just the pure joy of baking pastries, customizing your cafe, and serving patient customers.

## ✨ Features

- 🥄 **Cursor-Driven Interactive Baking**:
  - **Recipe Paper & Steppers**: Use tactile `+` and `-` buttons to measure ingredients according to vintage recipe cards.
  - **Whisk & Stir**: Swirl your mouse in circles to whisk batter until fluffy, using a silver balloon whisk.
  - **Portion & Tray**: Spoon cookie dough and croissant rolls onto parchment baking sheets.
  - **Cozy Oven**: Watch pastries rise and bake to a golden brown with warm ambient glow and sweet oven bell chime.
  - **Decorate**: Add whipped cream, fresh berries, almonds, and icing sugar.
- 🏪 **Display Case & Relaxing Shop**:
  - Showcase freshly baked goods in clear glass display cases.
  - Friendly, patient customers visit without countdown timers.
  - Earn cozy coins 🪙 and level up your bakery.
- 🐱 **Bakery Upgrades & Decorations**:
  - Adopt a sleeping orange cat on the counter (+20% customer tips).
  - Add a vintage brass oven, daisy flower vase, and warm-light glass lamp.
  - Play lofi music on a classic gramophone.
- 🔊 **Built-in Web Audio SFX**:
  - Realistic procedural sounds (egg cracking, milk pouring, whisking, oven bell ding, coin clinks).
  - Toggleable relaxing Lofi BGM chime loop.
- 💾 **Auto-Save**:
  - Saves your bakery level, coins, unlocked recipes, and showcase stock to `localStorage`.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm

### Installation & Run
```bash
# Clone the repository
git clone https://github.com/wosangxr/Baking-games.git

# Navigate into project directory
cd Baking-games

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:5173/](http://localhost:5173/) in your browser.

## 🛠️ Tech Stack

- **Framework**: React 19, TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS v4, Custom Pastel Color System
- **Icons**: Lucide React & Custom SVG Whisk
- **Audio**: Web Audio API (procedural synthesis)
- **Effects**: Canvas Confetti
